# Repository Note

English | [Українська](REPOSITORY_UK.md) | [Deutsch](REPOSITORY_DE.md)

This repository contains generated GitHub Pages output only.
Source of truth: `radiova-platform-private/apps/web`
Published output: `docs/`

Do not edit files inside docs/ manually. They are generated by the private monorepo production build.

## Purpose

This repository publishes the public Radiova website.
It keeps the generated site, the public documentation, and the GitHub Pages workflow.

## Deployment flow

1. Build the site in the private monorepo.
2. Copy the generated output into `docs/`.
3. Commit the updated public repository.
4. GitHub Pages serves `docs/`.

## What belongs here

- generated `docs/`
- public repository documentation
- GitHub workflow and repository templates

## What does not belong here

- source code
- package manifests
- build dependencies
- local build caches
- manual edits to `docs/`

## Expected Git status after a production copy

- `docs/` should reflect the latest published site output.
- No source directories should reappear.
- No package or build files should be present.
- Documentation files should stay in sync with the deployment-only role.
