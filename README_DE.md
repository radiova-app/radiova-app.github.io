## Website-Überblick

Radiova ist eine statische Astro-Seite und PWA zum Hören von Radiosendern und Verwalten von Playlists.
Unterstützte Browser: moderne Chromium-, Firefox- und Safari-Versionen.
PWA funktioniert am besten in Chromium-basierten Browsern; auf iPhone und iPad erfolgt die Installation über Safari über den Home-Bildschirm.
Datenschutz: Player-Status, Einstellungen, Playlists und Einwilligung bleiben im Browser.
