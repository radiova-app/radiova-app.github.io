# Нотатка про репозиторій

[English](REPOSITORY.md) | Українська | [Deutsch](REPOSITORY_DE.md)

Цей репозиторій містить лише згенерований вміст GitHub Pages.
Джерело правди: `radiova-platform-private/apps/web`
Опублікований результат: `docs/`

Не редагуйте файли всередині docs/ вручну. Їх створює production-збірка приватного monorepo.

## Призначення

Цей репозиторій публікує сайт Radiova для загального доступу.
Він зберігає згенерований сайт, публічну документацію та workflow для GitHub Pages.

## Потік публікації

1. Зберіть сайт у приватному monorepo.
2. Скопіюйте згенерований результат у `docs/`.
3. Закомітьте оновлений публічний репозиторій.
4. GitHub Pages обслуговує `docs/`.

## Що належить сюди

- згенерований `docs/`
- документація публічного репозиторію
- workflow та шаблони репозиторію

## Що сюди не належить

- вихідний код
- package-файли
- залежності для збірки
- локальні кеші збірки
- ручні правки `docs/`

## Очікуваний Git status після production copy

- `docs/` має відображати останній опублікований стан сайту.
- Каталоги з вихідним кодом не повинні повертатися.
- Package- і build-файлів не повинно бути.
- Документація має залишатися узгодженою з deployment-only роллю.
