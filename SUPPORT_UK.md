# Підтримка

Цей репозиторій містить лише згенерований вміст GitHub Pages.
Джерело правди: `radiova-platform-private/apps/web`
Опублікований результат: `docs/`

Не редагуйте файли всередині docs/ вручну. Їх створює production-збірка приватного monorepo.

## Перед тим як повідомляти про проблему

- Зробіть жорстке оновлення сторінки.
- Перевірте інший браузер.
- Очистіть дані сайту, якщо застосунок завис.
- Для перевірки відтворення або сховища переконайтеся, що згоду вже прийнято.

## Встановлення PWA

- Браузери Chromium: використайте кнопку встановлення, коли вона з'явиться.
- iPhone та iPad: відкрийте сайт у Safari, потім Share > Add to Home Screen.
- Firefox і Safari на desktop можуть поводитися інакше, ніж Chromium.

## Аудіо та візуалізатор

- Якщо аудіо не відтворюється, вкажіть станцію і браузер.
- Візуалізатор може бути обмежений заголовками CORS потоку.
- Станція може грати навіть тоді, коли візуалізатор статичний.

## Очищення даних сайту

Якщо плеєр, мова або згода поводяться дивно, очистіть дані сайту для домену і перезавантажте сторінку.

## Зламані станції

Використайте шаблон для broken station і додайте:

- назву станції
- сторінку або плейлист
- URL потоку, якщо відомий
- браузер і пристрій
- час збою
- чи спрацював fallback-потік або візуальний стан
