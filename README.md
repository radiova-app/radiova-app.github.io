## Site summary

Radiova is a static Astro site and PWA for listening to radio streams and managing playlists.
Supported browsers: modern Chromium, Firefox, and Safari.
PWA support is best on Chromium-based browsers; iOS uses Safari home-screen installation.
Privacy summary: player state, preferences, playlists, and consent data stay in the browser.
