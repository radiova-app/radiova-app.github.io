# Contributing to Radiova

English | [Українська](CONTRIBUTING_UK.md) | [Deutsch](CONTRIBUTING_DE.md)

This repository contains generated GitHub Pages output only.
Source of truth: `radiova-platform-private/apps/web`
Published output: `docs/`

Do not edit files inside docs/ manually. They are generated by the private monorepo production build.

## What belongs here

- bug reports
- broken station reports
- translation corrections
- accessibility feedback
- documentation fixes

## What does not belong here

- application source changes
- Astro, TypeScript, Node, or test files
- package manifests or build dependencies
- manual edits inside `docs/`

## Good reports include

- route or page
- browser and version
- operating system
- device model
- viewport size if relevant
- consent mode or privacy mode
- steps to reproduce
- expected result
- actual result
- screenshots or screen recordings when helpful

## Mobile and responsive issues

If the issue is visual on mobile, include the exact device, browser, orientation, and viewport if known.
Say whether the problem happens on the homepage, a language page, or a settings screen.

## Privacy

Do not post personal data, tokens, or private station credentials.
If a report touches browser storage, explain only what the user sees.

## Communication

Keep feedback respectful and specific.
Assume good faith.
Use the issue templates when possible.
