# Код поведінки

English | Українська | [Deutsch](CODE_OF_CONDUCT.de.md)

Цей репозиторій містить лише згенерований вміст GitHub Pages.
Джерело правди: `radiova-platform-private/apps/web`
Опублікований результат: `docs/`

Не редагуйте файли всередині docs/ вручну. Їх створює production-збірка приватного monorepo.

## Очікувана поведінка

- Пишіть ввічливо і конкретно.
- Не допускайте образ, переслідування або дискримінації.
- Не засмічуйте issues, коментарі або шаблони.
- Не надсилайте шкідливі дані станцій або небезпечні посилання.

## Повідомлення про проблему

Для публічних звернень використовуйте шаблони issues або сторінку Support.
Для питань безпеки використовуйте політику Security.

## Сфера дії

Цей код поведінки стосується issues, pull request'ів, коментарів і обговорень у репозиторії.
Мейнтейнерам дозволено прибирати вміст, який порушує ці правила.
