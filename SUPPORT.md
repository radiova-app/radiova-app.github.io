## Before reporting an issue

- Try a hard refresh.
- Check another browser.
- Clear site data if the app is stuck.
- Make sure consent has been accepted when testing playback or storage.

## PWA installation

- Chromium browsers: use the install button when it appears.
- iPhone and iPad: use Safari, then Share > Add to Home Screen.
- Firefox and Safari desktop may show different install behavior than Chromium.

## Audio and visualizer

- If audio does not play, report the station and browser.
- Visualizer behavior can be limited by stream CORS headers.
- A station can play even when the visualizer is static.

## Clearing site data

If playback, language, or consent behaves strangely, clear site data for the domain and reload.

## Broken stations

Use the broken station issue template and include:

- station name
- page or playlist
- stream URL if known
- browser and device
- time of the failure
- whether a fallback stream or visual state worked
